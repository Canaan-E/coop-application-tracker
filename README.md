# Co-op Application Tracker

A Java application for organizing and tracking co-op and internship applications throughout the recruitment process.

## Features

- Add and view job applications
- Update application statuses
- Remove applications
- Search by company or position
- Filter applications by status
- Save and load application data
- Validate user input

## Application Statuses

- Saved
- Applied
- Interview
- Offer
- Rejected

## Technologies

- Java
- Object-oriented programming
- Java Collections
- File I/O
- Exception handling

## Project Structure

- `JobApplication` represents an individual job application
- `ApplicationManager` manages stored applications
- `ApplicationStatus` defines the available recruitment stages
- `FileManager` handles persistent data storage
- `Main` provides the interactive console interface
